# RAPIRA COMMUNITY Registration Bot

Telegram-бот для регистрации участников с модерацией заявок, SQLite-хранилищем и выдачей персональной ссылки-приглашения только после одобрения.

## Возможности

- Последовательный сбор игрового ника, RAPIRA ID и Telegram username.
- Подтверждение введённых данных перед отправкой заявки.
- Одна ожидающая заявка на пользователя; повторные нажатия и устаревшие кнопки безопасно обрабатываются.
- Уведомления администраторов с данными пользователя и кнопками решения.
- Проверка Telegram ID администратора при каждом решении.
- Персональная ссылка в закрытую группу создаётся только после одобрения и ограничивается одним участником.
- Заявки и незавершённые регистрации сохраняются в SQLite.

## Настройка

1. Создайте бота через [@BotFather](https://t.me/BotFather) и скопируйте токен.
2. Добавьте бота в закрытую группу, задайте ему право приглашать пользователей и получите ID чата группы (обычно начинается с `-100`).
3. Узнайте Telegram ID каждого модератора. Укажите список через запятую в `ADMIN_IDS`. Для группы модерации задайте `ADMIN_CHAT_ID`; без него бот отправляет заявки каждому ID из `ADMIN_IDS` (администраторы должны предварительно открыть бота и нажать `/start`).
4. Скопируйте `.env.example` в `.env` и заполните значения. Не публикуйте `.env` и токен бота.

`GROUP_CHAT_ID` должен указывать именно на закрытую группу, куда бот может создавать ссылки-приглашения. Ссылка выдаётся индивидуально, с лимитом в одно вступление и сроком действия 7 дней.

## Запуск через Docker Compose

```bash
cp .env.example .env
# заполните .env
docker compose up -d --build
```

Контейнер перезапускается автоматически, база хранится в Docker volume `bot-data`. Логи: `docker compose logs -f bot`.

## Запуск локально

Нужен Python 3.11 или новее.

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
set -a
. ./.env
set +a
python bot.py
```

Бот использует long polling, поэтому для одного токена должен работать только один экземпляр. Для постоянной работы используйте Docker Compose или менеджер процессов с политикой автоматического перезапуска.
